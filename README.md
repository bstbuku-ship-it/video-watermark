# 视频批量加水印工具

当前版本：v1.5.4

批量为本地视频添加文字水印，内置 FFmpeg，支持 NVIDIA / Intel / AMD 显卡加速，提供多档输出质量，下载即用。

## 下载使用

前往 [Releases](../../releases) 页面下载最新版。提供三种版本：

| 版本 | 文件名 | 说明 |
| --- | --- | --- |
| 单文件版 | `video-watermark-vX.Y.Z.exe` | 一个 EXE 文件，下载后双击即可运行，方便直接使用和分享。 |
| 绿色便携版 | `video-watermark-vX.Y.Z-Portable.zip` | 解压后为完整的软件文件夹，直接运行其中的 `视频加水印.exe`，无需安装，可整体复制到其他位置或电脑使用。 |
| 安装版 | `video-watermark-vX.Y.Z-Setup.exe` | 运行安装程序，可自定义安装到任意磁盘和文件夹，之后从开始菜单或桌面快捷方式启动。 |

以上版本均不需要另外安装 Python 或 FFmpeg。

## 功能

**水印设置**

* 水印位置、大小、颜色、透明度、边距均可调
* 支持文字描边（可调粗细）和半透明背景块，浅色视频上的水印也能看清
* 提供 6 款字体：通用无衬线（Arial）、微软界面字体（Segoe UI）、办公风格（Calibri）、现代简洁（Roboto）、清晰易读（Open Sans）、醒目标题（Montserrat）
* 处理前可点击“预览水印”查看实际效果，支持整体预览与水印局部预览

**批量处理**

* 批量拖拽添加视频（MP4 / MKV / MOV / AVI / WMV 等）
* 统一输出格式，默认 MP4；支持 MP4 / MKV / MOV / M4V / TS / FLV
* 输入视频已经是所选输出格式时，不做额外的格式转换
* 输出质量五档：极压 CRF35 / 压缩 CRF28 / 快速 CRF23 / 高质量 CRF18 / 近乎无损 CRF10
* 自动检测显卡硬件加速（NVIDIA / Intel / AMD），支持 RTX 50 系列，也可手动指定编码器
* 支持自定义输出目录和文件名前缀
* 开始处理前会再次确认；处理中自动锁定参数，防止误操作
* 完成后再次拖入视频时自动清空已完成记录，方便连续处理

**使用体验**

* 夜间 / 日间主题切换，关闭后自动保存所有设置
* 启动阶段优化：FFmpeg 与编码器检测在后台执行，减少界面等待
* 内置版本检测；安装版可在后台下载新版安装包并自动完成更新，无需手动卸载旧版本
* 绿色便携版采用完整 OneDir 结构，解压后即可运行

## 运行环境

* Windows 10/11 x64
* 无需安装 Python 或 FFmpeg
* 使用 Roboto、Open Sans、Montserrat 三款字体时，首次需要联网下载，之后会缓存在本机，不再重复下载
