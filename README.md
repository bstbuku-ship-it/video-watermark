# 视频批量加水印工具

> 当前版本：v1.5.1

批量为本地视频添加文字水印，内置 FFmpeg，支持 NVIDIA/Intel/AMD 显卡加速，提供多档输出质量，下载即用。

## 下载使用

前往 [Releases](../../releases) 页面下载最新版。

提供三种版本：

* **单文件版（OneFile）**：一个 EXE 文件，下载后双击即可运行，方便直接使用和分享。
* **绿色便携版（Portable）**：解压后为完整的软件文件夹，直接运行其中的 `VideoWatermark.exe`，无需安装，可将整个文件夹复制到其他位置或电脑使用。
* **安装版（Setup）**：运行安装程序，可自定义安装到任意可用磁盘和文件夹；安装完成后从开始菜单或桌面快捷方式启动。

以上版本均不需要用户另外安装 Python 或 FFmpeg。

## 功能

* 批量拖拽添加视频（MP4 MKV MOV AVI WMV 等）
* 统一输出视频格式（默认 MP4），支持 MP4 / MKV / MOV / M4V / TS / FLV；输入已经是所选格式时不做额外的格式后缀转换，其他格式按所选格式输出
* 自定义字体（Arial / Segoe UI / Calibri）
* 水印位置、大小、颜色、透明度、边距全部可调
* 自动检测显卡硬件加速（NVIDIA / Intel / AMD），支持 RTX 50 系列
* 输出质量五档：极压 CRF35 / 压缩 CRF28 / 快速 CRF23 / 高质量 CRF18 / 近乎无损 CRF10
* 处理中锁定参数，防止误操作
* 完成后拖入新文件自动清空旧记录
* 自定义输出目录和文件名前缀

## 运行环境

Windows 10/11 x64，无需安装 Python 或 FFmpeg。
