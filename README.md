# 视频批量加水印工具

> 当前版本：v1.5.2

批量为本地视频添加文字水印，内置 FFmpeg，支持 NVIDIA/Intel/AMD 显卡加速，提供多档输出质量，下载即用。

## 下载使用

前往 [Releases](../../releases) 页面下载最新版。

提供三种版本：

* **单文件版（OneFile）**：一个 EXE 文件，下载后双击即可运行，方便直接使用和分享。
* **绿色便携版（Portable）**：解压后为完整的软件文件夹，直接运行其中的 `VideoWatermark.exe`，无需安装，可将整个文件夹复制到其他位置或电脑使用。
* **安装版（Setup）**：运行安装程序，可自定义安装到任意可用磁盘和文件夹；安装完成后从开始菜单或桌面快捷方式启动。

以上版本均不需要用户另外安装 Python 或 FFmpeg。

## 功能

* 批量拖拽添加视频（MP4 / MKV / MOV / AVI / WMV 等）
* 统一输出视频格式，默认 MP4；支持 MP4 / MKV / MOV / M4V / TS / FLV
* 输入视频已经是所选输出格式时，不做额外的后缀转换；其他格式按所选格式输出
* 自定义字体（Arial / Segoe UI / Calibri）
* 水印位置、大小、颜色、透明度、边距均可调
* 自动检测显卡硬件加速（NVIDIA / Intel / AMD），支持 RTX 50 系列
* 输出质量五档：极压 CRF35 / 压缩 CRF28 / 快速 CRF23 / 高质量 CRF18 / 近乎无损 CRF10
* 处理中自动锁定参数，防止误操作
* 完成后再次拖入视频时自动清空已完成记录，方便连续处理
* 支持自定义输出目录和文件名前缀
* 内置版本检测与更新功能
* 安装版支持后台下载新版安装包并自动完成更新，无需手动卸载旧版本
* 启动阶段优化，FFmpeg 与编码器检测在后台执行，减少界面等待
* 绿色便携版采用完整 OneDir 结构，解压后即可运行，无需安装

## 运行环境

Windows 10/11 x64，无需安装 Python 或 FFmpeg。

## 更新日志

### v1.5.2

* **新增后台自动更新机制**：安装版检测到新版本后，可在软件内直接下载新版安装包并自动执行更新
* **更新过程后台运行**：新版安装包在后台下载，不阻塞主界面正常使用
* **自动校验更新文件**：支持对下载的安装包进行 SHA-256 校验，降低文件下载不完整或损坏的风险
* **自动完成安装与重启**：更新安装包下载完成后自动启动静默安装，完成后重新打开软件
* **区分安装版与便携版**：安装版支持软件内自动更新；绿色便携版保持免安装特性，可通过 Releases 下载新版
* **优化启动体验**：保留启动画面，并继续将 FFmpeg、编码器等启动检测放到后台执行，减少启动阶段卡顿
* **优化发布版本结构**：统一提供单文件版、绿色便携版和安装版三种发行方式
* **统一 Release 文件命名**：发行文件采用英文名称，方便下载、管理和后续自动更新
* **保持原有功能**：水印、输出格式、质量档位、硬件加速、主题及参数设置等功能保持不变
